gymbrot.gymbrot_point_nav_system.gymbrot_point_nav_system.initial_pose_pub

ROS2 Node for publishing initial robot pose estimation.

This node publishes a single initial pose estimate for robot localization systems like AMCL (Adaptive Monte Carlo Localization).
